# Experience Configuration

See [Experience Format](/developer/architecture/experience-format) for complete configuration documentation.

## Quick Reference

```json
{
  "version": "1.0.0",
  "title": "Experience Title",
  "description": "Description",
  "agents": { ... },
  "resources": { ... },
  "aiConfigurations": { ... }
}
```

## Key Sections

- **Metadata**: Version, title, description
- **AI Configurations**: Provider and model settings
- **Agents**: Agent definitions
- **Resources**: Scenes, sounds, instructions
- **Initial Agent**: Starting agent key
