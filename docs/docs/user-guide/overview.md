# User Guide Overview

Welcome to the Primer User Guide! This section helps you understand and use Primer effectively.

## What You'll Learn

- **[What is Primer?](/user-guide/what-is-primer)** - Understanding Primer's purpose and capabilities
- **[Key Concepts](/user-guide/key-concepts)** - Core concepts and terminology
- **[Getting Started](/user-guide/getting-started)** - Your first steps with Primer
- **[Using Experiences](/user-guide/using-experiences)** - Tips for effective interactions

## Who This Is For

This guide is for anyone who wants to:
- Understand what Primer does
- Learn how to interact with AI experiences
- Get the most out of voice-based AI interactions
- Explore interactive AI scenarios

## No Technical Knowledge Required

You don't need to be a programmer or have technical expertise to use Primer. This guide explains everything in plain language.

## Ready to Start?

Jump to [What is Primer?](/user-guide/what-is-primer) to learn about the platform, or go straight to [Getting Started](/user-guide/getting-started) if you're ready to try it out!
