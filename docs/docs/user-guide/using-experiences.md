# Using Experiences Effectively

Get the most out of Primer with these tips and best practices.

## Understanding Experience Types

### Educational
- Tutoring and one-on-one learning
- Practice and skill-building
- Assessment and quizzes

### Professional
- Role-play scenarios
- Coaching and development
- Brainstorming and analysis

### Creative
- Collaborative writing
- Design and planning
- Problem-solving

## Maximizing Your Interactions

### Be Specific

❌ "Help me with this"  
✅ "I need help understanding the delegation system"

### Ask for What You Need

- "Can you create a summary as a bulleted list?"
- "Please show me a visual diagram"
- "Break this down step-by-step"

### Provide Feedback

- "That's not quite what I meant. Let me clarify..."
- "Can you try a different approach?"
- "That's perfect!"

## Working with Artifacts

**During the Session**:
- Request artifacts explicitly
- Review as you go
- Request revisions

**After the Session**:
- Download important artifacts
- Share with others
- Return to review

## Troubleshooting

### Audio Problems
- Use headphones for echo/feedback
- Check internet connection for delays
- Speak clearly if misunderstood

### Interaction Issues
- Wait for processing to complete
- Rephrase if misunderstood
- Check browser console for errors

## Best Practices

1. **Come prepared** with materials if needed
2. **Set clear goals** for what you want to accomplish
3. **Take notes** to supplement AI-generated content
4. **Save your work** by downloading artifacts
5. **Experiment freely** - it's a safe environment

## Privacy and Data

**What's Stored**: Session metadata, artifacts, transcripts (if enabled)

**What's Not Stored**: Audio recordings of your voice, credentials

## Getting Help

- Say "help" during experiences
- Check this documentation
- Report issues with clear details
