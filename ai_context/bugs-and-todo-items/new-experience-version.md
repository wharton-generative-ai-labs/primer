When the Experience Builder agent makes experiences, it copies from a template experience. These template experiences already have version numbers, which might not be 1.0 since the templates themselves are evolved over time. It's useful to have a non 1.0 version for the template to keep track of which one is in use.

However, when a new Experience is created from a template, it ought to start from 1.0

Make the Experience Builder set the version of the newly created Experience to 1.0
